# Automated-Sales-Summary-Invoicing-Systemthe schedule or manual trigger, the workflow starts by fetching all orders from your store. Next, it splits into multiple branches to calculate the overall sales summary, product-specific sales, customer analysis, and refunds. These datasets are then merged together and formatted into a final sales report, which is appended as a new row in your spreadsheet. Simultaneously, it prepares invoice data, generates the HTML, converts it to a file, and uses the PDFco API to create a PDF. Finally, the PDF is uploaded to Google Drive, and notification messages are sent to keep everyone updated.
